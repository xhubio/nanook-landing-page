# Static Data

Source: https://nanook.xhub.io/docs/guide/generatrorCommand/static

Static data is the simplest kind of data. All entries not starting with 'gen:' or 'ref:' are interpreted as static data. This data is just copied to the 'testcaseData' object as is.
