API Reference

The interfaces and classes of every Nanook module, grouped the way the packages are.

This reference describes Nanook 1.x (JavaScript). Since 2.0 (March 2026) Nanook is TypeScript/ESM; Processor is now TestcaseProcessor, TDGServiceRegistry is DataGeneratorRegistry. The current reference lives in the repository: docs/api.

model

The base contracts — TableInterface, TestcaseDefinitionInterface — and the four Todo classes.

model-decision

Decision tables: TableDecision, TestcaseDefinitionDecision, the section types, and the validate functions.

model-matrix

Matrix tables: TableMatrix and TestcaseDefinitionMatrix.

dataGenerator

Data generation: DataGeneratorInterface, DataGeneratorBase, GeneratorFaker, and the TDGServiceRegistry (DataGeneratorRegistry in 3.x).

processor

Test case processing: InterfaceProcessor, InterfaceWriter, Processor (TestcaseProcessor in 3.x), the data classes (Node, Reference, TestcaseData), and the write and filter helpers.

file-processor

File handling: FileProcessor, ImporterInterface, ParserInterface, and the decision, matrix, and specification parsers.

importerXlsx

The Excel importer: ImporterXlsx.

logger

Logging: LoggerInterface and LoggerMemory.
