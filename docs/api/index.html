API Reference

The interfaces and classes of every Nanook module, grouped the way the packages are.

model

The base contracts — TableInterface, TestcaseDefinitionInterface — and the four Todo classes.

model-decision

Decision tables: TableDecision, TestcaseDefinitionDecision, the section types, and the validate functions.

model-matrix

Matrix tables: TableMatrix and TestcaseDefinitionMatrix.

dataGenerator

Data generation: DataGeneratorInterface, DataGeneratorBase, GeneratorFaker, and the TDGServiceRegistry.

processor

Test case processing: InterfaceProcessor, InterfaceWriter, Processor, the data classes (Node, Reference, TestcaseData), and the write and filter helpers.

file-processor

File handling: FileProcessor, ImporterInterface, ParserInterface, and the decision, matrix, and specification parsers.

importerXlsx

The Excel importer: ImporterXlsx.

logger

Logging: LoggerInterface and LoggerMemory.
