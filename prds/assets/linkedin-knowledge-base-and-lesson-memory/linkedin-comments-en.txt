=== Comment 1 — Torsten Link (author; first comment under the post, within the first hour) ===

What I learned from keeping this memory: a lesson needs the mechanism, not only the incident. "Don't do X in file Y" helps once. "A tool that skips a check silently turns every skipped check into an assurance" helps everywhere.

And: memories go stale. A note that names a file, a function or a flag describes the state at the time it was written. Before the agent acts on it, it checks that the thing still exists. Both stores are claims about the past that the present has to confirm.
