=== Comment 1 — Torsten Link (author; first comment under the post, within the first hour) ===

What the post leaves out: why one change so often touches ten or more repositories. The e-invoicing API (https://invoice-api.xhub.io), the software for trades businesses (https://dashandwerk.xhub.io) and the PDF API share the same plugins and backends. A bug in a shared package is a bug in all apps, so it is fixed in all of them at the same time. This rule is marked critical in the instruction file. An agent that fixed the bug in the app in front of it thinks the job is done.

And a trap you have to live through once: a green CI run without a release publishes nothing. If the branch is behind the remote, semantic-release skips silently.
